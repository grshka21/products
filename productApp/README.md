# Warehouse Encapsulation

Практическая работа по ООП (C#) и работе с Git по модели Git-Flow.

## Реализованные задачи
1. **Минимальный остаток (`Product`)**: контроль минимального порога запасов (`MinStock`, `SetMinStock`) и свойство `IsBelowMinStock`.
2. **Поставщики (`Supplier`)**: валидация имени, телефона и ИНН (10/12 цифр), защищённая привязка поставщика через `AssignSupplier`.
3. **Списание товаров (`WriteOff`)**: учёт списанных единиц (`WrittenOffTotal`) с проверкой причины и переиспользованием `RemoveStock`.

## Запуск
```bash
dotnet run
```
